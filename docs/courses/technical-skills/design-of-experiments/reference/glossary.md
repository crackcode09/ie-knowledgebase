# Glossary

- **Alias (confounding):** two or more effects that share one column in a fractional design and cannot be separated.
- **Balanced design:** every cell has the same number of runs.
- **Block:** a group of similar experimental units used to remove a known nuisance source.
- **Center point:** a run with every factor at its mid-level, used to estimate pure error and test for curvature.
- **Coded units:** factor levels scaled to −1 (low) and +1 (high).
- **Completely randomized design (CRD):** treatments assigned to units fully at random.
- **Confirmation run:** a run at the chosen settings to check the model's prediction.
- **Defining relation:** the set of words equal to I in a fractional factorial (for example, I = ABCDE).
- **Effect:** the change in mean response when a factor moves from low to high.
- **Effect sparsity:** the principle that few effects are large.
- **Experimental unit:** the item to which one treatment is applied.
- **Factor:** an input deliberately varied.
- **Factorial design:** a design that runs all combinations of factor levels.
- **Fold-over:** a second fraction with signs reversed, used to break aliases.
- **Generator:** the rule that sets an extra factor's column (for example, E = ABCD).
- **Interaction:** the effect of one factor depends on the level of another.
- **Latin square:** a p × p layout in which each treatment appears once per row and once per column.
- **Lenth's method:** a robust estimate of effect noise for unreplicated 2^k designs.
- **Level:** a setting of a factor.
- **Main effect:** the average effect of a factor across the levels of all other factors.
- **OFAT:** one factor at a time, an inefficient approach that cannot see interactions.
- **Orthogonal:** design columns that are uncorrelated, so effects are estimated independently.
- **Power:** the probability of detecting a true difference of a given size.
- **Randomization:** random assignment and run order, which protects against unknown nuisance factors.
- **Randomized complete block design (RCBD):** every treatment is run once within each block.
- **Replicate:** an independent repeat of a treatment on a new experimental unit.
- **Resolution:** the length of the shortest word in the defining relation. It indicates what is aliased with what.
- **Response:** the measured output.
- **Treatment:** a combination of factor levels.
- **Type I / II / III sums of squares:** sequential, hierarchical-adjusted and fully adjusted SS. They differ only for unbalanced data.
