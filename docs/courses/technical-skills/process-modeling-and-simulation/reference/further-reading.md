# Further Reading

| Source | Why read it |
|---|---|
| Law, A. M. *Simulation Modeling and Analysis*, 5th ed. McGraw-Hill, 2015. | Standard reference on DES, input modeling, output analysis |
| Banks, J., Carson, J. S., Nelson, B. L., & Nicol, D. M. *Discrete-Event System Simulation*, 5th ed. Pearson, 2010. | Textbook on DES, verification and validation |
| Robinson, S. *Simulation: The Practice of Model Development and Use*, 2nd ed. Palgrave Macmillan, 2014. | Practical modeling process, conceptual models, stakeholder use |
| Sargent, R. G. (2013). "Verification and validation of simulation models." *Journal of Simulation*, 7(1), 12–24. | V&V techniques |
| Hopp, W. J., & Spearman, M. L. *Factory Physics*, 3rd ed. Waveland, 2011. | Variability, utilization and queueing (Module 9) |
| Kingman, J. F. C. (1961). "The single server queue in heavy traffic." *Mathematical Proceedings of the Cambridge Philosophical Society*, 57(4), 902–904. | Kingman approximation |
| SimPy documentation. https://simpy.readthedocs.io/ | Open-source Python DES library for larger models |
