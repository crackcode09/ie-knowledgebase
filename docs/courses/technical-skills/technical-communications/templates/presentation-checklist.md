# Presentation Checklist

## Content
- [ ] Purpose statement written; the decision maker is named
- [ ] The ask is on slide 1, with amount, owner and date
- [ ] Every slide title is a full-sentence takeaway
- [ ] One idea per slide; about 40 words or fewer on each content slide
- [ ] Acronyms removed or defined
- [ ] Every number has a comparison, a unit and sensible rounding
- [ ] Uncertainty and assumptions are stated
- [ ] Each chart's message is in its title (see reference/chart-chooser.md)
- [ ] The appendix covers the top ten feared questions
- [ ] Numbers checked against their sources; totals add up

## Rehearsal
- [ ] Rehearsed aloud and timed, with about 1/3 of the slot left for questions
- [ ] At least one reviewer from outside the project
- [ ] Feedback grouped (Pareto); top issues fixed

## Logistics
- [ ] File tested on the meeting-room computer or in the remote-meeting tool
- [ ] Backup copy available
- [ ] One-page summary or pre-read sent, if appropriate

## After
- [ ] Decision, actions, owners and dates sent within 24 hours
- [ ] Lessons noted for next time
