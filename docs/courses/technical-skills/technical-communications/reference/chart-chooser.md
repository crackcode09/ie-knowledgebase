# Chart Chooser

| Your message | Use | Tips |
|---|---|---|
| X changed over time | line or run chart | mark events; label phase means; one highlighted series |
| X is bigger than Y (ranking) | sorted horizontal bar | sort by value; label the bars; highlight the ones that matter |
| X is part of a whole | sorted bar or stacked bar | use a pie only for 2 or 3 parts |
| Before vs after | line with phase means, or paired bars | same scale; show the spread or interval |
| X relates to Y | scatter | add a trend line only if you'll discuss it |
| How values are spread | histogram or box plot | show spec limits if relevant |
| Many categories over time | small multiples | same axes in every panel |
| Exact values | small table | units in the header; align decimals; bold the key cell |
| Process stability | control chart | see the Charting Process Behavior course |

## Checklist for every chart

- [ ] The title states the takeaway
- [ ] Axes are labeled, with units
- [ ] The scale is honest (bars and percentages start at zero)
- [ ] Color is used only to highlight, and never as the only cue
- [ ] Data is labeled directly; no legend, or a minimal one
- [ ] No 3-D, no dual axes unless unavoidable, light or no gridlines
- [ ] Source and date are noted in small print
- [ ] Readable from the back of the room
