# Formula Sheet

## Statements

- Assets = liabilities + equity
- Gross profit = revenue − COGS
- EBIT = gross profit − SG&A − depreciation
- EBITDA = EBIT + depreciation and amortization
- Net income = (EBIT − interest) × (1 − t)
- Retained earnings (end) = retained earnings (start) + net income − dividends
- CFO = net income + depreciation − Δ operating assets + Δ operating liabilities
- Free cash flow = CFO − capex
- Unlevered FCF = EBIT (1 − t) + depreciation − capex − Δ working capital

## Ratios

| Ratio | Formula |
|---|---|
| Gross, EBIT, net margin | profit line / revenue |
| ROA | net income / average total assets |
| ROE | net income / average equity = margin × turnover × equity multiplier |
| Asset turnover | revenue / average total assets |
| DSO | receivables / revenue × 365 |
| DIO | inventory / COGS × 365 |
| DPO | payables / COGS × 365 |
| Cash conversion cycle | DSO + DIO − DPO |
| Current ratio | current assets / current liabilities |
| Quick ratio | (cash + receivables) / current liabilities |
| Debt / equity | total debt / equity |
| Debt / EBITDA | total debt / EBITDA |
| Interest coverage | EBIT / interest |

## Budget variances (+ favorable)

- Sales volume = flexible-budget profit − static-budget profit
- Price = (actual price − standard price) × actual units
- Material price = (standard price − actual price) × actual quantity
- Material usage = (standard quantity − actual quantity) × standard price
- Labor rate = (standard rate − actual rate) × actual hours
- Labor efficiency = (standard hours − actual hours) × standard rate
- Spending = budget − actual

## Time value of money (rate r per period, n periods)

- FV = PV (1 + r)^n
- PV = FV / (1 + r)^n
- PV annuity = A [1 − (1 + r)^−n] / r
- FV annuity = A [(1 + r)^n − 1] / r
- Payment = P r / [1 − (1 + r)^−n]
- Perpetuity = A / r; growing perpetuity = A₁ / (r − g)
- Effective annual rate = (1 + APR/m)^m − 1

## Cost of capital

- Bond price = coupon × PV annuity factor + face / (1 + y)^n
- k_d after tax = k_d (1 − t)
- CAPM: k_e = r_f + β (market risk premium)
- WACC = (E/V) k_e + (D/V) k_d (1 − t)

## Investment

- OCF = savings (1 − t) + depreciation × t
- After-tax salvage = salvage − t (salvage − book value)
- NPV = Σ CF_t / (1 + r)^t
- IRR: NPV(IRR) = 0
- Profitability index = PV of future cash flows / initial investment
- Accounting ROI = average net income / average investment
- EAC = PV of costs × r / [1 − (1 + r)^−n]

## Break-even

- CM per unit = price − variable cost per unit
- Break-even units = fixed cost / CM
- Target-profit units = (fixed cost + target) / CM
- Margin of safety = (planned − break-even) / planned
- DOL = contribution / operating profit
- Indifference volume = Δ fixed cost / Δ variable cost per unit

## Valuation

- Terminal value = FCF_{n+1} / (WACC − g)
- Equity value = enterprise value − (debt − cash)
