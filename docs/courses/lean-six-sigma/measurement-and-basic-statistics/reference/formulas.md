# Formulas — One-Page Reference

| Quantity | Formula |
|---|---|
| Mean | x̄ = Σx / n |
| Median | Middle value of sorted data (average of middle two if n even) |
| Range | max − min |
| Variance | s² = Σ(x − x̄)² / (n − 1) |
| Standard deviation | s = √s² |
| IQR | Q3 − Q1 |
| Coefficient of variation | CV = s / x̄ × 100% |
| z-score | z = (x − μ) / σ |
| DPU | defects / units |
| DPMO | defects / (units × opportunities) × 1,000,000 |
| First-pass yield | units passing first time / units started |
| Pareto % | category total / grand total × 100; cumulative % = running sum |

## Histogram bins

Start with about √n bins (5–20), round the width to a convenient number.
