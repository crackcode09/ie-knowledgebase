# Glossary

**Accuracy (bias)** — How close the average measurement is to the true value.

**Attribute (discrete) data** — Counts or categories.

**Central tendency** — Where data cluster: mean, median, mode.

**Coefficient of variation (CV)** — Standard deviation as a percentage of the mean.

**Common-cause variation** — Routine variation from many small sources built into the process.

**Continuous (variable) data** — Measurements on a scale.

**CTQ** — Critical-to-quality characteristic with a target and specification limits.

**Defect / defective** — A single nonconformance / a unit with one or more defects.

**Descriptive statistics** — Summaries of the data at hand.

**DPMO / DPU** — Defects per million opportunities / defects per unit.

**Histogram** — Bars showing how often values fall in each bin of a continuous scale.

**Inferential statistics** — Conclusions about a population or process from a sample.

**IQR** — Interquartile range, Q3 − Q1: the spread of the middle 50%.

**Mean / median / mode** — Arithmetic average / middle value / most frequent value.

**Nominal, ordinal, interval, ratio** — Measurement scales from categories without order to measurements with a true zero.

**Normal distribution** — Symmetric bell-shaped distribution defined by μ and σ.

**Operational definition** — A precise description of how to obtain a measurement or classify an item.

**Parameter / statistic** — A population value / a sample value that estimates it.

**Pareto chart** — Bars sorted from largest to smallest with a cumulative-percent line.

**Population / sample** — All items of interest / the items measured.

**Precision (repeatability)** — How close repeated measurements are to each other.

**Range** — Max − min.

**Resolution** — The smallest change a measurement system can detect.

**Special-cause variation** — Variation from a specific, identifiable event.

**Standard deviation** — The typical distance of values from the mean.

**Stratification** — Splitting data by a grouping factor to reveal hidden differences.

**z-score** — Number of standard deviations a value lies from the mean.
