# Module 2 — Descriptive vs Inferential Statistics

**Time:** 20 min

## Learning objectives

1. Distinguish descriptive from inferential statistics.
2. Recognize when a conclusion goes beyond the data.

## 1. Two jobs

| | Descriptive | Inferential |
|---|---|---|
| Purpose | Summarize the data you have | Draw conclusions about the population or process the data came from |
| Tools | Tables, charts, mean, median, standard deviation | Confidence intervals, hypothesis tests, process behavior charts |
| Example statement | "The 100 shafts measured averaged 12.7001 mm." | "We're 95% confident the process mean is between 12.698 and 12.702 mm." |
| Risk | Misleading summaries (Module 8) | Wrong conclusions if the sample isn't representative or the process isn't stable |

## 2. The bridge: a representative sample

Inference only works if the sample represents the population. Threats:

- **Convenience sampling** — measuring the first parts of the shift only.
- **Survivorship** — measuring only parts that passed inspection.
- **Time** — a process that drifts means "the population" keeps changing. Shewhart's point: for a process, the question is usually "is it stable enough to predict?", which a process behavior chart answers (see *Charting Process Behavior*).

## Check yourself

Classify each statement as descriptive (D) or inferential (I):

1. "Last month 41% of complaints were late deliveries."
2. "Next month we expect between 35% and 47% of complaints to be late deliveries."
3. "Supplier B's parts varied more than supplier A's in this sample."
4. "Supplier B's process produces more variation than A's."

<details><summary>Answers</summary>

1. D. 2. I. 3. D. 4. I.
</details>
