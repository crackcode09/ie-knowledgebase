# Module 2 — Pre-Event Planning: Charter, SIPOC, Plan

**Time:** 2.5 h

## Learning objectives

1. Prepare a kaizen event: scope, team, logistics and data.
2. Write a kaizen charter.
3. Build a SIPOC and a Gantt-style event plan.

## 1. Why pre-work decides success

Most failed kaizen events fail before Monday: scope too big, wrong team, no data, no sponsor time, materials not ordered, maintenance not available. Plan 3–6 weeks ahead.

## 2. The charter

| Field | Carriage cell example |
|---|---|
| Event name | Carriage assembly & pack — flow kaizen |
| Sponsor / process owner | Operations manager / cell supervisor |
| Problem statement | For 20 days the cell averaged 465 carriages/day vs demand of 560 (−17%), with 5,170 units of WIP and 9.2 days lead time |
| Scope | From kit release to packed carriage. **Out:** rail machining, shipping |
| Goals | Output ≥ 560/day; WIP −50%; lead time ≤ 4 days; no added headcount; no safety or quality degradation |
| Team (6–8) | 2 cell operators, 1 operator from another cell (fresh eyes), setter, quality tech, maintenance tech, manufacturing engineer; leader + co-facilitator |
| Dates | Pre-work weeks −5 to −1; event Mon–Fri; follow-up 30/60/90 days |
| Constraints | Budget $5,000 for fixtures and racks; production must ship ≥ 400/day during the event week |
| Report-out | Friday 1:00 pm, plant leadership |

## 3. SIPOC

A high-level map that agrees the boundaries before the detail.

| Suppliers | Inputs | Process (5–7 steps) | Outputs | Customers |
|---|---|---|---|---|
| Machining cell | Carriage blocks | Kitting | Packed carriages | Shipping |
| Purchasing / supplier | Balls, seals, end caps | Ball insert | Test records | OEM customers |
| Stores | Grease, packaging | Preload set | Scrap / rework | Quality |
| Production control | Daily schedule | Seal & lube | | |
| Maintenance | Fixtures, test rig | Friction test → Pack | | |

## 4. Event-preparation checklist

| Item | Owner | When |
|---|---|---|
| Sponsor signs charter | Leader | Week −5 |
| Team selected, released by supervisors | Sponsor | Week −4 |
| Baseline data collected (output, WIP, changeover times, defects) | Engineer | Weeks −4 to −1 |
| Build-ahead so the line can ship during the event | Production control | Weeks −2 to −1 |
| Maintenance, IT, safety on call for the week | Leader | Week −2 |
| Room, supplies (tape, labels, stopwatches, carts), lunches | Co-facilitator | Week −1 |
| Communicate to everyone affected | Supervisor | Week −1 |

## Check yourself

The sponsor wants to "fix the whole assembly department" in one event. What do you do?

<details><summary>Answer</summary>

Narrow the scope to one value stream segment the team can change in a week (e.g., one cell), using data on where the biggest gap is. Plan follow-on events for the rest.
</details>
