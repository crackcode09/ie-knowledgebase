# Module 14 — Team Member Track: The One-Day, Ten-Step Kaizen

**Time:** 1 day (can be taken on its own)

For people who will **take part** in kaizen events, or run a short one-day improvement on a single problem found during value stream mapping. It follows Plan–Do–Check–Act in ten steps. Read Modules 0, 4 and 5 first (about 3 hours) if taking this track alone.

## The ten steps

| # | Step | PDCA | Output | Course reference |
|---|---|---|---|---|
| 1 | Define kaizen and agree ground rules | Plan | Shared understanding | Modules 0, 3 |
| 2 | Pick one specific problem from the value stream map | Plan | Selected problem | Module 5 |
| 3 | Write the problem statement | Plan | Measurable statement | Module 2 |
| 4 | Observe the area — go to the gemba | Plan | Observations, photos, times | Module 4 |
| 5 | Gather critical data | Plan | Baseline numbers | Modules 1, 4 |
| 6 | Analyze — identify causes | Plan | Fishbone, 5-Why | Module 7 |
| 7 | Generate and select solutions as a team | Plan | Chosen solution | Modules 7, 10 |
| 8 | Develop the implementation plan | Plan | Who/what/when | Module 2 |
| 9 | Implement | Do | Changed process | Modules 8–10 |
| 10 | Check results and document the changes | Check / Act | Before/after data, updated standard work | Modules 12–13 |

## Example — one-day kaizen: kanban for seal kits

| Step | Content |
|---|---|
| Problem | Operators at the seal station run out of seal kits 2–3 times per shift; each stockout stops the line for ~8 min |
| Data | 10 days: 27 stockouts, 216 min lost (≈ 21.6 min/day at the constraint's downstream step) |
| Cause | Kits delivered once per shift in one big batch; no signal when low; storage far from station |
| Solution | Two-bin kanban at point of use (bin = 2 hours of use); empty bin returned to stores is the signal |
| Implement | Bins, labels, rack, route change for material handler — done by 2 pm |
| Check | Next 10 days: 1 stockout (handler absent); add backup handler to route |
| Document | Updated standard work for handler and operator; photo of standard rack |

## Check yourself

Which PDCA phase do steps 2–8 belong to, and why is it so long?

<details><summary>Answer</summary>

Plan. Most of the value is in understanding the problem and choosing the right fix; implementing a well-understood fix is fast.
</details>
