## Pre-work checklist

- [ ] Charter signed (week −5)
- [ ] Team selected and released (week −4)
- [ ] Baseline data collected (weeks −4 to −1)
- [ ] Build-ahead / production plan for event week (weeks −2 to −1)
- [ ] Support functions booked (week −2)
- [ ] Room, supplies, materials, lunches (week −1)
- [ ] Communication to affected people (week −1)
