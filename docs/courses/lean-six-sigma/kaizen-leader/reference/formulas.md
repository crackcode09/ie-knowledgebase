# Formulas and Quick Reference

| Measure | Formula |
|---|---|
| Takt time | available time ÷ customer demand |
| Lead time (Little's law) | WIP ÷ throughput (VSM convention: ÷ daily demand) |
| Inventory days | units waiting ÷ daily demand |
| Process cycle efficiency | value-added time ÷ lead time |
| Effective cycle time | cycle time ÷ uptime |
| Capacity | available time ÷ effective cycle time |
| Minimum operators | ⌈total work content ÷ takt⌉ |
| Balance efficiency | total work content ÷ (operators × takt) |
| Kanban cards | daily demand × replenishment time × (1 + safety) ÷ container qty |
| OEE | availability × performance × quality |
| Availability | run time ÷ planned time |
| Performance | (ideal cycle time × total units) ÷ run time |
| Quality | good units ÷ total units |
| Hourly target | 3,600 ÷ takt (s) |

## Kaizen week at a glance

| Day | Focus | Key tools |
|---|---|---|
| Pre-work | Scope, charter, team, baseline | Charter, SIPOC, Gantt |
| Mon | Current state | Gemba walk, process map, spaghetti, VSM, takt, TOC |
| Tue | Causes and ideas | Fishbone, 5-Why, scatter, brainstorming |
| Wed–Thu | Implement | Flow, balancing, pull, SMED, FMEA, error-proofing, pilot |
| Fri | Standardize, report | 5S, visual management, standard work, control plan, report-out |
| +30/60/90 | Sustain | Audits, charts, open actions |
