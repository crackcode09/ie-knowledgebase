# Further Reading

| Source | Why read it |
|---|---|
| Ishikawa, K. *Guide to Quality Control*. Asian Productivity Organization, 1976 (English ed.). | Fishbone, Pareto, stratification, scatter — the "seven basic tools" |
| Ohno, T. *Toyota Production System: Beyond Large-Scale Production*. Productivity Press, 1988. | Origin of the 5-Why practice |
| Kepner, C. H., & Tregoe, B. B. *The New Rational Manager*. Princeton Research Press, 1981. | Is / Is-Not problem analysis |
| Andersen, B., & Fagerhaug, T. *Root Cause Analysis: Simplified Tools and Techniques*, 2nd ed. ASQ Quality Press, 2006. | Practical RCA toolbox |
| Shingo, S. *Zero Quality Control: Source Inspection and the Poka-Yoke System*. Productivity Press, 1986. | Error-proofing (Module 13) |
| Montgomery, D. C., Peck, E. A., & Vining, G. G. *Introduction to Linear Regression Analysis*. Wiley. | Regression, residuals, multicollinearity (Modules 10–11) |
| Hosmer, D. W., Lemeshow, S., & Sturdivant, R. X. *Applied Logistic Regression*, 3rd ed. Wiley, 2013. | Logistic regression (Module 12) |
| NIST/SEMATECH *e-Handbook of Statistical Methods*, Ch. 4 "Process Modeling". https://www.itl.nist.gov/div898/handbook/ | Free reference on regression |
| Sobek, D. K., & Smalley, A. *Understanding A3 Thinking*. Productivity Press, 2008. | A3 problem-solving reports (Capstone) |
