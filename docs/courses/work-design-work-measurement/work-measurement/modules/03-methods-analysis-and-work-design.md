# Module 03 — Methods Analysis and Work Design

## Objectives

- Apply methods analysis before measurement: "fix the method, then measure."
- Use questioning techniques and motion-economy principles to improve work.
- Design work for productivity, quality, safety and ergonomics.

## Method first

A standard measures a method. Measure a poor method and you get an accurate standard for waste. The sequence is:

1. Select the job (high volume, high cost, bottleneck, quality or safety issues).
2. Record the present method (Module 02 charts).
3. Examine it critically.
4. Develop the improved method.
5. Install it, train, and let it stabilize.
6. **Then** measure and set the standard.

## Questioning technique

For each activity ask **what, why, where, when, who, how** — and then the ECRS sequence:

| Step | Question | Marlow example |
|---|---|---|
| **Eliminate** | Is it needed at all? | Visual inspection in E5 duplicates the leak test for some defects — keep only checks the test can't do |
| **Combine** | Can steps merge? | Label applied while the pump is still in the fixture |
| **Rearrange** | Better sequence? | Assemble the next pump during the leak test (Module 02) |
| **Simplify** | Easier way? | Screw presenter and torque-controlled driver for the 6 screws in E3 |

## Motion economy and workplace design

- Both hands working simultaneously and symmetrically where possible.
- Tools and parts in fixed locations within the normal reach area; gravity-feed bins; drop delivery.
- Fixtures instead of hands for holding; foot or automatic actuation where suitable.
- Work height suited to the task (fine work higher; heavy work lower); adjustable for different people.
- Minimize search and select: presentation in orientation, kitting.

## Work design beyond motions

Good work design also considers:

- **Ergonomics** — posture, force, repetition, lifting (see the ergonomics content in [Introduction to Industrial Engineering](../../introduction-to-industrial-engineering/README.md)). Fatigue factors feed allowances (Module 07).
- **Quality** — error-proofing built into the method.
- **Variety and job rotation** — for repetitive work.
- **Training and standard work** — the method is documented and taught consistently.

## Effect on the Marlow standard

Present method normal time: 108.4 s per pump (63.4 s manual + 45.0 s machine). If the operator assembles the next pump during the test, and the manual work (63.4 s plus allowances) is longer than the test, the cycle becomes the manual time with allowances — about **72.9 s** instead of **117.9 s** — a **38 %** reduction in standard time per pump from a methods change alone. (Check: the tester then runs 45 s of every 73 s; no second tester is needed.)

## Check yourself

1. Why let a new method stabilize before measuring?
2. Which ECRS step gave the biggest gain at Marlow?

<details><summary>Answers</summary>

1. Operators need time to learn it (learning curve, Module 13); measuring too early produces a loose standard, or an unfair rating judgment.
2. Rearrange — doing manual work while the machine runs (internal work), removing 45 s of waiting per cycle.
