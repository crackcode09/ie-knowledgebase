## Facilitator notes

- **Module 01:** start with the "2,080 vs available hours" exercise. It is the quickest way to show why definitions matter.
- **Module 02:** the seven-type grouping is this course's. If participants' organizations use another taxonomy, map it onto these seven.
- **Module 03:** discuss the waiting-time policy question with HR and labor relations in mind. It is a real negotiation point.
- **Module 05:** let learners guess the counter staffing from workload alone, then reveal the queueing result.
- **Module 07:** the disagreement between the two retirement estimates is intentional. Ask which one learners would present, and how.
- **Module 08:** the back-test is the most persuasive slide for executives. Make sure learners can build it.
- **Throughout:** costs, the retirement rule, the new-hire factor and the peer data are illustrative. Replace them with local values.
