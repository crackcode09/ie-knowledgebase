# Module 12 — Movements: Key Rules

## Objectives

- Apply the key rules that keep movement coding consistent between analysts.

## Rules on the teaching card

1. **Classify by body member, not distance.** Use the distance guides only to help you see which body member moves.
2. **Every movement ends in a terminal activity.** Pair each A-code with a get or a put, even if it is G0 or P0.
3. **Code the limiting member** when two movements happen at once. The shorter one is hidden inside it.
4. **Simultaneous movements are allowed only with low conscious control** at both ends. If either hand needs eye guidance (G5, P6), the hands work one after the other (Module 14).
5. **Weight doesn't change the movement code.** Add a load factor (L1) for each loaded movement (Module 19).
6. **Holding is not a motion.** A hand that only holds is not coded.
7. **Code what the method requires**, not habits. Extra hand motions done out of habit are left out of a standard but noted for training.
8. **Repeated movements are written with a multiplier** (A2x3), so the count stays visible.

## Why rules matter

Two analysts coding the same video should get the same total. Most disagreements come from rule 3 (simultaneous motions) and rule 4 (conscious control). Practise those cases on purpose.

## Check yourself

1. The right hand reaches 40 cm for a screw (selective get) while the left hand reaches 20 cm for a washer (simple get). How is this coded?
2. An operator taps the part twice before placing it, out of habit. Is that coded?
