# Module 08 — MODAPTS Codes (and the Teaching Code Card)

## Objectives

- Describe the three classes of codes in a MODAPTS-style system.
- Read the teaching code card used for all practice in this course.

## Three classes

Public descriptions list MODAPTS codes such as Movement, Get (grasp), Put and auxiliary activities like Walk and Read, each written as a letter plus an integer ([Eisbrenner PG](https://eisbrennerpg.com/about-modapts/)). The outline of this course follows the same three classes:

| Class | Role in a motion sequence | Course modules |
|---|---|---|
| **Movement** | Transporting the hand or a body member (empty or loaded) | 09–12 |
| **Terminal** | What happens at the end of a movement: **Get** (gain control) or **Put** (place) | 13–17 |
| **Auxiliary** | Everything else: body motions, eyes, reading, deciding, pressure, walking, loads | 18–19 |

The official MODAPTS code card belongs to the IMA. This course **does not reproduce it**.

## The teaching code card

All values are original to this course and **illustrative**: 1 U = 0.1 s. The full card is in `data/teaching_code_card.csv` and `reference/teaching-code-card.md`.

| Class | Codes |
|---|---|
| Movement | A2 finger · A3 hand · A4 forearm · A6 arm · A8 extended arm · A12 arm + trunk |
| Get | G0 contact · G2 simple · G5 selective (eyes guide the fingers) |
| Put | P0 toss/release · P3 one alignment, loose · P6 two or more alignments or a tight fit · C2 each extra correction |
| Auxiliary | W6 walk/step · F4 foot action · B22 bend and arise · S20 sit · U22 stand · E3 eye focus · R2 read/word · D3 decide · X5 apply pressure · T2 transfer/regrasp · K6 crank/revolution · L1 load factor |
| Process | PT*n*: tool or machine time in U |

## Check yourself

1. Which class does "apply pressure to snap a cover" belong to?
2. Is a reach to a part a terminal activity?

<details><summary>Answers</summary>

1. Auxiliary (X5 on the teaching card).
2. No. The reach is a **movement**. The **get** at the end of it is the terminal activity.

</details>
