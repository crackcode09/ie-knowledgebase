# Method Improvement Checklist (from a coded analysis)

Work through the coded sheet line by line.

## Eliminate

- [ ] Walking (W): can material come to the operator (lift table, flow rack, chute)?
- [ ] Bending (B): can material be presented between knee and shoulder height?
- [ ] Reading and deciding (R, D): can a scanner, colour code or poka-yoke replace them?
- [ ] Gets after a put while the object is still in hand: remove them

## Simplify terminals

- [ ] Each G5: present parts separated and oriented (trays, gravity feed, dispensers) → G2
- [ ] Each P6 and C2: chamfers, funnels, self-locating features, more clearance → P3
- [ ] Lifting where sliding works: G0 … P0

## Shorten movements

- [ ] Each A8 or A12: move the item into the normal work area → A6 or A4
- [ ] Tools hung at the point of use (balancers) → shorter moves, P0 asides

## Use both hands

- [ ] Once gets and puts are low control, can the two hands work at the same time?
