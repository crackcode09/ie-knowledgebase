# Glossary

| Term | Meaning |
|---|---|
| **Aggregate error** | Error of the total of many predicted jobs vs their actual total; smaller than per-job error when errors are random |
| **Allowance (PF&D)** | Time added to normal time for personal needs, fatigue and unavoidable delay |
| **Constant element** | An element whose time doesn't depend on job features |
| **Cook's distance** | A measure of how much one observation changes the fitted model |
| **Correlation coefficient (r)** | Strength and direction of a straight-line relationship, −1 to +1 |
| **Cross-validation** | Testing a model on data not used to fit it; leave-one-out uses each observation in turn |
| **Data sheet** | The published table of element codes, times, frequencies and ranges |
| **Driving variable** | A job feature that determines element time, such as bends or weight |
| **Dummy (indicator) variable** | A 0/1 variable for a yes/no feature |
| **Element** | A defined piece of work with clear start and end points |
| **Extrapolation** | Using a model outside the range of the data it was built from; *hidden* extrapolation is outside the joint range even when each variable is inside its own |
| **Frequency** | How often an element occurs per unit (per lot, per piece, per bend) |
| **Hold-out (validation) data** | Studies kept aside to test the model |
| **Intercept** | The constant term of a regression; in standard data, the constant element |
| **Macroscopic standard data** | Element-, operation- or task-level data, usually from regression on time studies |
| **Microscopic standard data** | Motion-level data, usually from a PMTS |
| **Multicollinearity** | Strong relationships among predictors that make coefficients unstable |
| **Normal time** | Time for a qualified worker at normal pace, before allowances |
| **PMTS** | Predetermined motion time system: tables of normal times for basic motions |
| **Prediction interval** | Range expected to contain one new observation |
| **R²** | Share of variation in the response explained by the model |
| **Residual** | Observed minus predicted value |
| **Standard data system** | A catalogue of element times and formulas used to set standards without new studies |
| **Standard error of estimate** | Typical size of residuals, in the response's units |
| **Studentized residual** | A residual divided by its estimated standard deviation; \|value\| > 3 signals a problem |
| **Variable element** | An element whose time depends on a job feature |
| **VIF** | Variance inflation factor; measures multicollinearity for each predictor |
