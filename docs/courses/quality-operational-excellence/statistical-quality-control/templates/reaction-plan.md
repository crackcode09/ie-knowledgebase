# Control Chart Reaction Plan

| Field | Entry |
|---|---|
| Process / characteristic | |
| Chart type, subgroup size, frequency | |
| Control limits (date set) | |

| Signal | Immediate action (operator) | Containment | Escalate to | Record |
|---|---|---|---|---|
| Point beyond a control limit | Stop, check the last parts, check setting, tool and material | Hold parts since the last good subgroup | Supervisor / process engineer | Note on chart + log |
| 2 of 3 beyond 2σ, or 4 of 5 beyond 1σ | Check for shift (tool wear, offset, material lot) | Increase sampling until resolved | Process engineer | Note on chart |
| 8 in a row on one side | Look for a sustained change; verify gauge | — | Process engineer | Note on chart |
| R or MR chart signal | Check fixture, gauge, material variation | Measure additional parts | Process engineer | Note on chart |
| Part out of specification | Follow nonconforming-product procedure | Quarantine | Quality | NCR |

Do **not** adjust the process when there is no signal.
