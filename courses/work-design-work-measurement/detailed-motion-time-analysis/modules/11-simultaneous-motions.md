# Module 11 — Simultaneous Motions

## Objectives

- Decide when the two hands can work at the same time.
- Apply the limiting-motion rule.

## Why it matters

When both hands work at once, only the **longer** (limiting) side counts. When they can't, the times add up. Getting this right is the biggest single source of differences between analysts.

## The teaching card's rule (course convention)

Each motion is either **low control** or **high control**:

| High control (needs the eyes and attention) | Low control |
|---|---|
| Reach cases c, d | Reach cases a, b |
| Move case c | Move cases a, b |
| Grasps Gs, Gx | Grasps Gc, Gp, Gr, Gt |
| All positions except PLS | PLS, release, turn, apply pressure, DL |
| Disengage DC, DT | |

**Rule:**

- If **both** hands contain a high-control motion in the same step, they work **one after the other**, and the times add.
- Otherwise they work **at the same time**, and the step time is the **larger** of the two.

| Left hand | Right hand | Result |
|---|---|---|
| R30b Gp (45) | R30b Gp (45) | Simultaneous → **45** |
| R30b Gx (56) | R30b Gp (45) | One high → simultaneous → **56** |
| R30c Gx (65) | R30b Gs (50) | Both high → sequential → **115** |
| M20b PLS RL (39) | M20b PLS RL (39) | Simultaneous → **39** |
| M20c PCS RL (56) | M20c PCS RL (56) | Both high → **112** |

Real systems use more detailed rules, considering the area of normal vision, how far apart the targets are, and practice. This simplified rule teaches the reasoning. It doesn't reproduce any system's table.

## Design implication

To get two-handed work, make **at least one hand's work low control**: oriented parts (Gp instead of Gx), loose symmetric placements (PLS), fixtures. Module 13 applies this.
