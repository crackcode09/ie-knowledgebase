# Module 01 — What Is Methods-Time Measurement?

## Objectives

- Describe MTM-1 and its place among work measurement methods.
- State the key public facts about its origin and ownership.
- Understand what this open course teaches and what only the licensing bodies provide.

## In brief

**Methods-Time Measurement (MTM)** is a **predetermined motion time system**. A manual operation is broken into **basic motions** (reach, grasp, move, position, release and others), and each motion gets a predetermined time that depends on the **conditions** under which it is done: distance, weight, the type of grasp, how precisely an object must be placed. **MTM-1** is the original, most detailed form ([Wikipedia: Methods-time measurement](https://en.wikipedia.org/wiki/Methods-time_measurement)).

## Public facts

| Fact | Source |
|---|---|
| Basic data developed in the 1940s by H. B. Maynard, J. L. Schwab and G. J. Stegemerten (Methods Engineering Council) during work at Westinghouse | [Wikipedia](https://en.wikipedia.org/wiki/Methods-time_measurement) |
| Book *Methods-Time Measurement* published 1948 | Same |
| Data developed from films of qualified workers, analysed frame by frame and levelled to a common performance | Same |
| 1951: USA/Canada MTM Association for Standards and Research formed; the originators assigned it the MTM copyrights | Same |
| Later systems: MTM-2 (1965), MTM-3 (1970), MTM-UAS (mid-1970s) and others, built on MTM-1 | Same |
| Copyright in MTM-1 and several later systems is held today by MTM Association e.V. (Hamburg), centre of the One-MTM network (as stated on the cited page) | Same |
| 1 TMU (time measurement unit) = 0.00001 hour = 0.036 s | Same |
| The course this outline follows awards "BlueCard" certification in MTM-1 to participants who complete it | Course page |

## About this course

MTM-1's data card, application rules and manuals are copyrighted by the MTM associations. This course therefore:

- teaches the **method** of a detailed, distance- and condition-based PMTS: the motion categories, the variables that drive their times, simultaneous-motion reasoning, methods analysis, and standard setting;
- uses an **original Detailed Teaching Card (DTC)** for all practice (`data/card_*.csv`). The DTC's classes, codes and values are the course's own. They are **not MTM data** and are **not valid for real standards**;
- points learners to the MTM associations for licensed training, the official data card and certification.

This course is not affiliated with or endorsed by any MTM association.
