# Module 09 — Release and Disengage

## Objectives

- Code release and disengage motions.
- Recognize recoil and care as time drivers.

## Release

**Release** lets go of an object. It is usually short.

| Code | cs | Use |
|---|---|---|
| RL | 2 | Normal: open the fingers |
| RLc | 0 | Contact release: the hand simply moves away (after a contact grasp) |

## Disengage

**Disengage** breaks contact between one object and another, as when pulling a part off locating pins or a plug from a socket. Effort and **recoil** (the hand jumping when the object comes free) take time.

| Code | cs | Meaning | High control? |
|---|---|---|---|
| DL | 4 | Loose: no effort, little recoil | no |
| DC | 10 | Close: some effort, recoil | yes |
| DT | 30 | Tight: high effort, marked recoil | yes |
| suffix c | +5 | Care needed to avoid damage or injury | |

## Check yourself

1. Pull a part off two close-fitting pins, taking care not to scratch it.
2. Lift a stamp off paper.

<details><summary>Answers</summary>

1. **DCc** = 10 + 5 = **15 cs**.
2. **DL** = **4 cs** (no effort, no recoil).

</details>
