# Module 03 — Methods Analysis

## Objectives

- Describe a method precisely enough to analyse its motions.
- Build a left-hand/right-hand (two-handed) chart.
- Apply methods-analysis questions before measuring.

## Method first

A detailed PMTS measures **a method**. A poor method measured precisely is still a poor method. Before coding, define:

| Item | Example |
|---|---|
| Workplace layout | Bin positions and distances, fixture location, chute |
| Parts and tools | Sizes, weights, how they are presented (loose, oriented, magazine) |
| Fits and tolerances | Clearance of the pin in the hole; chamfers |
| Sequence | Which hand does what, in what order |
| Quality checks | What is inspected, and how |
| Process times | Machine or tool cycles |

## The two-handed chart

List each hand's motions side by side, step by step. A hand that does nothing is **idle**; a hand that only grips is **holding**. Both are signals for improvement.

| Step | Left hand | Right hand |
|---|---|---|
| 1 | Reach to bolt, pick up | idle |
| 2 | Move bolt in front of body | idle |
| 3 | **hold** | Reach to washer, pick up |
| 4 | **hold** | Move washer to bolt |
| 5 | **hold** | Position washer, release |
| 6 | Move assembly to chute, release | idle |

This is Lab 3, current method. Module 13 codes and improves it.

## Methods-analysis questions

- **Eliminate:** is the motion needed at all? Could a chute, gravity or a fixture do it?
- **Combine:** can two motions be done at once by both hands?
- **Rearrange:** would a different sequence avoid regrasps or long moves?
- **Simplify:**
  - Shorten distances.
  - Present parts oriented and isolated (easier grasps).
  - Add chamfers and guides (easier positions).
  - Replace holding with fixtures.
  - Balance the work between the hands.

## Check yourself

From the chart above, how many steps have the left hand only holding, and how many have the right hand idle?

<details><summary>Answers</summary>

The left hand only holds in **3** steps (3–5). The right hand is idle in **3** steps (1, 2 and 6). Half of each hand's time is unproductive, so a fixture is the obvious first idea.
