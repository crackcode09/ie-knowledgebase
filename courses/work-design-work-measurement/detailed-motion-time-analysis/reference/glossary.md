# Glossary

| Term | Meaning |
|---|---|
| **Apply pressure** | Exerting force with little or no movement |
| **BlueCard** | MTM-1 practitioner certification awarded through licensed training (as named on the source course page) |
| **Case** | Classification of a reach or move by the control needed at its destination |
| **cs** | Centisecond, 0.01 s; this course's teaching unit |
| **Disengage** | Breaking contact between objects; includes effort and recoil |
| **Grasp** | Gaining control of an object with the fingers or hand |
| **High / low control** | Whether a motion needs the eyes and attention; governs simultaneous motions |
| **Limiting motion** | The longer of two simultaneous motions; it alone is counted |
| **Methods analysis** | Defining and improving the method before measuring it |
| **MTM-1** | The original, most detailed Methods-Time Measurement system (1948) |
| **Move** | Transporting an object with the hand |
| **Position** | Aligning, orienting and engaging one object with another |
| **Reach** | Moving the empty hand to a destination |
| **Release** | Letting go of an object |
| **SIMO chart** | Simultaneous-motion chart showing what each hand does over time |
| **TMU** | Time measurement unit: 0.00001 h = 0.036 s |
| **Turn** | Rotating the hand about the forearm's long axis |
| **Two-handed chart** | Left-hand/right-hand chart of a method |
