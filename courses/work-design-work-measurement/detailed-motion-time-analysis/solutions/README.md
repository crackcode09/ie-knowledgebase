## Facilitator notes

- **Module 01:** be explicit that the teaching card is not MTM. Learners heading for BlueCard certification will learn the official data and rules. The reasoning is what transfers.
- **Modules 04–10:** build a bench with real bins, fixtures and parts, and have learners measure distances and classify before coding.
- **Module 11:** demonstrate with both hands: pick two easy parts at once, then try two washers from a pile.
- **Module 15:** pair learners; have each code the same lab, then compare. Most differences will be classification (case, grasp, fit) or the assumed method.
- **Capstone:** expect several valid improved methods. Judge them on the reasoning and on correct use of the rules.
