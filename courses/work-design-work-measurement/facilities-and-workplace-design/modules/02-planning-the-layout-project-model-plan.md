# Module 02 — Planning the Layout · Project Model Plan

Outline items: **Planning the layout**, **Project model plan**

## Objectives

- Follow a structured procedure from data to an installed layout.
- Plan a layout project: phases, deliverables, approvals and participants.

## Planning the layout

A systematic layout procedure (this course's version, following the widely taught systematic-layout-planning approach):

```
Input data (P, Q, R, S, T)  ─►  Flow analysis  +  Activity relationships (affinities)
                                     │                     │
                                     └───► Relationship (configuration) diagram
                                                     │
            Space requirements  ─► Space available ─► Space relationship diagram
                                                     │
            Modifying considerations, practical limits ─► Alternative layouts (2–3)
                                                     │
                                         Evaluation ─► Selected layout ─► Detail ─► Install
```

The **input data** is often summarized as:

| Letter | Meaning | Corvan example |
|---|---|---|
| **P** | Products (what) | 40 SKUs in 4 families |
| **Q** | Quantities (how many) | 230,580 units/yr |
| **R** | Routings (how: process sequence) | Four family routings |
| **S** | Supporting services | Tool room, offices, maintenance, utilities |
| **T** | Timing (when, how fast) | 2 shifts, 230 days; growth plans |

## Project model plan

| Phase | Activities | Deliverable | Approval |
|---|---|---|---|
| 0 Charter | Objectives, scope, constraints, team, budget limit | Charter | Sponsor |
| 1 Information | P, Q, R, S, T; inventory and usage; site and building data | Data book | Team |
| 2 Analysis | Flow, affinities, space | Relationship and space diagrams | Team + operations |
| 3 Block alternatives | 2–3 block layouts | Alternatives with scores | Steering group |
| 4 Detail | Cells, workstations, aisles, utilities | Detailed layout, cell designs | Operations, EHS, maintenance |
| 5 Installation | Move sequence, downtime plan, start-up and ramp-up | Move plan | Sponsor |
| 6 Follow-up | Measure flow, lead time, safety and space use | Post-move review | Sponsor |

Participants:

- operators and supervisors (they know the real flow)
- maintenance and facilities (utilities, floors)
- EHS (safety, egress, fire separation)
- materials and logistics
- finance (capital)

Use the template `templates/layout-project-plan.md`.

## Check yourself

1. Which input letter covers the tool room and the offices?
2. Why develop 2–3 block alternatives rather than one?

<details><summary>Answers</summary>

1. **S**, supporting services.
2. Comparing alternatives exposes trade-offs (flow vs adjacency vs cost vs expansion) and builds agreement. A single option tends to be defended rather than evaluated.

</details>
