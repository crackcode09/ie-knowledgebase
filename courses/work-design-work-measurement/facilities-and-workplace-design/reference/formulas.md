# Formulas and Cheat Sheet

| Item | Formula |
|---|---|
| Loads | units ÷ units per load (container) |
| Flow between departments | Σ loads of all products moving from one to the other |
| Rectilinear distance | \|x₁ − x₂\| + \|y₁ − y₂\| between area centres |
| Flow × distance | Σ flowᵢⱼ × distanceᵢⱼ (load-metres per year) |
| Handling cost | load-metres × cost per load-metre |
| Adjacency score | Σ closeness weights of adjacent pairs (A 4, E 3, I 2, O 1, U 0, X −4; course weights) |
| Planning-unit space | machine footprint × (1 + work allowance) × (1 + aisle allowance), or a standard |
| Days of cover | on hand ÷ daily usage |
| Storage positions | volume at target ÷ (pallet volume × fill) |
| Available time | days × shifts × hours × 3,600 |
| Takt time | available time ÷ demand |
| Machine time per piece | machine cycle + load/unload (if the machine waits) + setup ÷ lot size |
| Machine capacity | available time × availability ÷ machine time per piece |
| Machines needed | demand ÷ capacity, rounded up |
| Operators | (manual time + walking) ÷ takt, rounded up |
| Balance efficiency | Σ operator loads ÷ (operators × largest load) |
| EPEI | Σ changeover times for all SKUs ÷ spare time per day |
| Kanbans | daily demand × lead time × (1 + safety) ÷ container quantity |
| Walking time | distance ÷ walking speed (≈1.2 m/s planning assumption) |
