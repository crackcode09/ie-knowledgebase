# Glossary

| Term | Meaning |
|---|---|
| **Affinity (closeness)** | How important it is for two planning units to be near each other (A, E, I, O, U, X) |
| **Backtrack** | A move against the main direction of flow |
| **Block layout** | Arrangement of planning units (areas) in the building |
| **Cell** | Group of different machines and people dedicated to a product family |
| **Configuration (relationship) diagram** | Nodes and lines showing planning units and their closeness |
| **EPEI** | Every part every interval: how often each product can be made, given setup time |
| **Exceptional element** | In cell formation, a part that needs a machine outside its cell |
| **From–to chart** | Matrix of flow between departments |
| **Functional (process) layout** | Similar machines grouped by function |
| **Heijunka** | Levelled, mixed production in a repeating sequence |
| **Kanban** | Signal (card or container) that authorizes replenishment |
| **Monument** | Equipment that is large or expensive to move (paint systems, big presses) |
| **Motion economy** | Principles for efficient use of the body, the workplace and tools |
| **P, Q, R, S, T** | Products, quantities, routings, supporting services, timing |
| **Pairwise exchange** | Layout improvement that swaps two units at a time if it reduces cost |
| **Planning unit** | An area treated as one block in layout planning |
| **P–Q analysis** | Product–quantity ranking used to choose layout types |
| **Rank order clustering (ROC)** | Binary-weight sorting of a part–machine matrix to find cells |
| **Takt time** | Available time ÷ demand: the pace of customer demand |
| **U-cell** | Cell in a U shape, with input and output close together |
| **Workstation layout** | Detailed design of one workplace: heights, reaches, tools, parts presentation |
