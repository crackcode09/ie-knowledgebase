# Cell Design Checklist

## Product and process

- [ ] Family defined (SKUs, volume at the planning horizon, routing)
- [ ] Process engineered (eliminate, combine, rearrange, simplify); quality checks at the source
- [ ] Operation times by an appropriate method (with accuracy noted)

## Capacity and people

- [ ] Takt time = available time ÷ demand
- [ ] Machine time per piece incl. load/unload and setup ÷ lot; utilization < ~85 % (or a plan)
- [ ] Operators = (manual + walk) ÷ takt; balance chart under takt
- [ ] Skills matrix; at least 2 people trained per position

## Layout

- [ ] Configuration chosen (U / L / straight); input next to output
- [ ] Operator path inside, maintenance and material access outside
- [ ] Reach, heights and parts presentation checked (workstation layout)
- [ ] Ergonomic risks reviewed; lifting assessed with a recognized method

## Running the cell

- [ ] Scheduling method (sequence, EPEI) and setup plan
- [ ] Containers, kanban quantities, addresses for every container
- [ ] Infrastructure: power, air, ventilation, lighting, floor, IT, visual board
- [ ] Supervision, team leader role, daily meeting
- [ ] Rewards support teamwork (skill pay, gainsharing, recognition)
- [ ] Mock-up and pilot done; 30/90-day follow-up scheduled
