# Time Study File Checklist

- [ ] Job / part / work center / date / analyst
- [ ] Purpose of the study; who was informed (supervisor, operator, representatives)
- [ ] Method description: sequence, tools, fixtures, workplace sketch with dimensions
- [ ] Conditions: material, equipment settings, quality requirements
- [ ] Element list with breakpoints and types (manual / machine / occasional)
- [ ] Raw readings (or video reference); foreign elements identified and explained
- [ ] Number of cycles vs required (formula and accuracy target)
- [ ] Ratings per element and basis (system used, benchmark)
- [ ] Allowances applied, convention (% of normal time or workday) and source
- [ ] Calculations: normal time, standard time, units per hour
- [ ] Approval signatures; communication to supervisor and operator
- [ ] Re-study triggers and next audit date
