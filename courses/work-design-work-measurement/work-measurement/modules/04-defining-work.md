# Module 04 — Defining Work

## Objectives

- Define the work unit and the task to be measured.
- Break a task into elements with clear breakpoints.
- Classify elements (manual, machine, constant, variable, occasional, foreign).

## Define the task

Before measuring, agree:

- **Work unit** — what one "count" is: one pump, one kit, one crate, one order line.
- **Start and end points** of the task.
- **Method** — documented (Module 02).
- **Quality standard** — what "done" means.
- **Conditions** — material, equipment, workplace layout.
- **Qualified worker** — trained, experienced, physically suited, working at normal pace.

## Elements

An **element** is a distinct, describable part of the task, timed separately. Rules of thumb:

- long enough to time accurately (often at least about 2–3 seconds with a stopwatch; video allows shorter);
- **clear breakpoints** — an audible or visible event that marks the end ("screwdriver released"; "pump touches tote floor");
- separate **manual** from **machine-controlled** elements (rating applies only to manual work);
- separate **constant** elements (same time for every variant) from **variable** elements (time depends on size, count, distance) — the basis for standard data (Module 12);
- record **occasional** elements (e.g. change a tote every 20 pumps) with their frequency;
- identify **foreign elements** (not part of the method — dropped tools, interruptions) so they can be excluded.

## Marlow pump assembly — element breakdown

| Element | Description | Type | Breakpoint (end) |
|---|---|---|---|
| E1 | Get housing, place in fixture | manual, constant | housing seated, hand released |
| E2 | Insert impeller and shaft | manual, constant | shaft clicks into bearing |
| E3 | Fit seal and cover, run 6 screws (power driver) | manual, variable (screw count) | driver placed in holder |
| E4 | Leak test (machine-controlled) | machine | tester green light |
| E5 | Attach label, inspect visually | manual, constant | hand leaves pump |
| E6 | Place in tote | manual, constant | pump touches tote floor |
| (occasional) | Exchange full tote (every 20 pumps) | manual, occasional | new tote in position |

## Why elements matter

- **Accuracy** — rating and outlier screening work better on short, consistent elements.
- **Diagnosis** — the time study shows which element varies (E3 and E5 here, Module 05).
- **Reuse** — constant elements become standard data for other pump models.
- **Method changes** — when only E3 changes, only E3 needs re-study.
