# Module 02 — The MODAPTS Acronym

## Objectives

- Expand the acronym and explain what each word means for an analyst.

## The words

**MOD**ular **A**rrangement of **P**redetermined **T**ime **S**tandards ([Eisbrenner PG](https://eisbrennerpg.com/about-modapts/); [6sigma.us](https://www.6sigma.us/work-measurement/modapts-modular-arrangement-of-predetermined-time-standards/)).

| Word | What it tells you |
|---|---|
| **Modular** | Every time value is a whole-number multiple of one basic unit (the **MOD**). Times are added like building blocks (Module 07) |
| **Arrangement** | The values are organized into classes (movements, terminal activities, auxiliary activities) so an analyst can find the right code quickly |
| **Predetermined** | The times were fixed in advance from research, not measured on the job being studied |
| **Time Standards** | The output is a normal time that, with allowances, becomes a work standard |

**MOD** also names the unit. Public sources give **1 MOD = 0.129 s**, which is about **7.75 MODs per second** ([Eisbrenner PG](https://eisbrennerpg.com/about-modapts/)). One secondary source expands "MOD" inconsistently ([6sigma.us](https://www.6sigma.us/work-measurement/modapts-modular-arrangement-of-predetermined-time-standards/)). Treat the IMA's manual as authoritative.

## Check yourself

1. Which word in the acronym tells you that values are whole numbers of one unit?
2. How many seconds are 20 MODs, using the public value?

<details><summary>Answers</summary>

1. **Modular**.
2. 20 × 0.129 = **2.58 s**.

</details>
