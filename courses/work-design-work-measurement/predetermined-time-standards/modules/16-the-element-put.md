# Module 16 — The Element PUT

## Objectives

- Choose the right put class from the fit and alignment needed.
- Use corrections, and design them out.

## Put classes on the teaching card

| Code | U | Use when | Examples |
|---|---|---|---|
| **P0** | 0 | **Release or toss**: no alignment | Drop in a bin; toss a bag into a tote; let go of a tool on a balancer |
| **P3** | 3 | **One alignment, loose fit**, low control | Place a carton against a stop; set a part in an open nest; put a tool to a large target |
| **P6** | 6 | **Two or more alignments, or a tight fit**, high control | Locate a housing on two pins; start a screw; insert a dowel pin |
| **C2** | 2 | **Each additional correction** during a P6 | The pin misses the bore and must be re-aligned |

## Decision steps

1. Is the object simply released? → P0.
2. Is a single loose alignment enough, without eye guidance? → P3.
3. Otherwise → P6, plus C2 for each correction the method normally needs.

## Designing out put time

| Feature | Effect |
|---|---|
| Chamfers, lead-ins, funnels | Fewer corrections; a P6 can become a P3 |
| Self-locating fixtures (one-way fit) | Removes orientation decisions |
| Larger clearance where function allows | Looser fit, so P3 |
| Tool guides (bit guides, nose pieces) | Faster engagement of screws |

## Check yourself

1. Code the put: hanging a tool back on a balancer hook; placing a label within a printed box; pressing a pin into a reamed hole with one typical correction.
2. If a lead-in chamfer turns `A4 P6 C2` into `A4 P3`, what is the saving per piece?

<details><summary>Answers</summary>

1. Balancer: P0 (release). Label in a box: P3 if the box is generous; P6 if it must be squared to an edge. Pin: **P6 C2**.
2. (4 + 6 + 2) − (4 + 3) = **5 U = 0.5 s** per piece.

</details>
