# Module 05 — Why Apply MODAPTS (and PMTS in General)

## Objectives

- List the business reasons for using a body-motion PMTS.
- Match each reason to a use at Kessler Components.

## Reasons

| Reason | What it means | Kessler example |
|---|---|---|
| **Standards without a stopwatch or rating** | Public sources stress this for MODAPTS ([Eisbrenner PG](https://eisbrennerpg.com/about-modapts/)) | No disputes about rating the operator's pace |
| **Before the job exists** | Code the planned method from a layout or mock-up | Standard for the new pin assembly before launch (Module 20) |
| **Method improvement** | Every second is tied to a motion you can eliminate, shorten or simplify | Kitting cut from 9.1 s to 3.8 s (Module 20) |
| **Ergonomics** | Codes show bends, long reaches, loaded moves and high-control work | Carton packing: 600 bends per shift removed (Module 20) |
| **Consistency** | Trained analysts coding the same method should get the same time | Standards that are comparable across lines |
| **Line balancing and staffing** | Element times are additive, so they can be reassigned between stations | Balancing a new cell |
| **Communication** | The code sheet documents the method in detail | Standard work instructions and training |
| **Workplace inclusion** | Public sources mention MODAPTS use in rehabilitation settings ([Eisbrenner PG](https://eisbrennerpg.com/about-modapts/)) | Matching tasks to individual capabilities (not covered further here) |

The same source claims an accuracy of "±5 % at the 95 % confidence level of the true mean" for MODAPTS. That claim comes from a practitioner's site and is **not independently verified** here.

## Limits to keep in mind

- A PMTS is only as good as the **method description**. Code the method the operator actually uses, not the one you wish they used, unless you are designing a new method.
- **Process and machine times** come from the equipment, not from motions.
- Highly **cognitive** work (diagnosis, programming) is outside what body-motion systems are built for.
- Real standards need the **licensed code card and trained analysts**.

## Check yourself

1. Give two reasons a PMTS helps ergonomics.
2. Why does "no rating" reduce labor disputes?

<details><summary>Answers</summary>

1. It counts exposures that can be designed out: bends, extended reaches, loaded moves and high-precision work. It also shows how much time each one takes, which helps justify the redesign.
2. Rating is a judgment about one person's pace and is often disputed. Predetermined values apply equally to everyone using the method.
