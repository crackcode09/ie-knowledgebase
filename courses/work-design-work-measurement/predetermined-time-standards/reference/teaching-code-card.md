# Teaching Code Card (OTC)

**Original to this course. Illustrative values for learning the method only. Not the MODAPTS card. Not validated for real standards.**

1 U = 0.1 s at normal pace. The number in each code is its time in U.

## Movement (body member)

| Code | U | Body member | Rough guide |
|---|---|---|---|
| A2 | 2 | Finger | ≤ 3 cm |
| A3 | 3 | Hand / wrist | 3–10 cm |
| A4 | 4 | Forearm | 10–25 cm |
| A6 | 6 | Whole arm | 25–45 cm |
| A8 | 8 | Extended arm with shoulder | 45–65 cm |
| A12 | 12 | Arm plus trunk lean, feet fixed | > 65 cm |

## Terminal: Get

| Code | U | Meaning |
|---|---|---|
| G0 | 0 | Contact get (no grasp) |
| G2 | 2 | Simple get, low control |
| G5 | 5 | Selective get: eyes guide the fingers |

## Terminal: Put

| Code | U | Meaning |
|---|---|---|
| P0 | 0 | Toss or release |
| P3 | 3 | One alignment, loose fit, low control |
| P6 | 6 | Two or more alignments, or a tight fit; high control |
| C2 | 2 | Each additional correction |

## Auxiliary

| Code | U | Meaning |
|---|---|---|
| W6 | 6 | Walk, per step |
| F4 | 4 | Foot or leg action |
| B22 | 22 | Bend and arise |
| S20 | 20 | Sit down |
| U22 | 22 | Stand up |
| E3 | 3 | Eye focus or travel |
| R2 | 2 | Read, per word or number group |
| D3 | 3 | Decide (simple) |
| X5 | 5 | Apply pressure without movement |
| T2 | 2 | Transfer or regrasp |
| K6 | 6 | Crank, per revolution |
| L1 | 1 | Load factor per loaded movement, per 2 kg above 2 kg per hand |

## Process

| Code | Meaning |
|---|---|
| PT*n* | Tool or machine time of *n* U, from the equipment |

## Key rules (summary)

1. Classify movements by the largest body member used.
2. Every movement ends in a get or a put (possibly G0 or P0).
3. Code the limiting hand for simultaneous low-control motions.
4. High-control gets and puts (G5, P6, C2) are done by one hand at a time.
5. Weight goes in L1, not in the movement code.
6. No new get while control of an object is kept.
7. Repetitions as code×n.
8. Allowances are added once, at the end.
