# Glossary

| Term | Meaning |
|---|---|
| **Auxiliary activity** | Any coded activity that is not a hand movement or terminal: body motions, eyes, reading, deciding, pressure, walking, load |
| **Body-member principle** | Movement time depends on the body member moved (finger to trunk) rather than exact distance |
| **Code symbol** | Letter for the type of activity plus an integer for its time in units |
| **Conscious control (low/high)** | How much eye guidance and attention a get or put needs; high control can't be overlapped between hands |
| **Correction** | Extra re-alignment during a precise put |
| **Get** | Terminal activity that gains control of an object |
| **IMA** | International MODAPTS Association, Inc.: owner of the MODAPTS trademark and copyright; runs certification |
| **Limiting member** | The longest of simultaneous motions; it alone is coded |
| **Load factor** | Extra time for movements that carry weight |
| **MOD** | MODAPTS base unit; 0.129 s (public value) |
| **MODAPTS** | MODular Arrangement of Predetermined Time Standards |
| **Modular concept** | All values are whole-number multiples of one base unit, so times add like blocks |
| **Movement** | Transport of a body member, empty (reach) or loaded (move) |
| **MTM** | Methods-Time Measurement; PMTS family first released in 1948 |
| **Normal time** | Time at a defined normal pace, before allowances |
| **PMTS** | Predetermined motion time system |
| **Process time** | Tool or machine time; taken from the equipment, not from motion codes |
| **Put** | Terminal activity that places an object at its destination |
| **Standard time** | Normal time plus allowances |
| **Terminal activity** | What happens at the end of a movement: a get or a put |
| **TMU** | Time measurement unit (MTM): 0.00001 h = 0.036 s |
| **U** | This course's teaching unit: 0.1 s |
