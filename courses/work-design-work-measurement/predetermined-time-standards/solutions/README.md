## Facilitator notes

- **Be explicit from Module 01** that the teaching card is not the MODAPTS card. Learners heading for IMA certification will relearn the official codes and values. The classification logic and rules of thumb are what transfer.
- **Modules 09–12:** use video of real tasks; have pairs code the same clip and compare totals. Most disagreements will be about simultaneous motions and conscious control.
- **Module 14:** the two-handed demonstration (picking easy parts vs washers from a pile with both hands) makes the high-control rule obvious.
- **Module 20:** build Task A's improved layout from cardboard and time it, then compare the measured time with the coded time.
- **Ergonomics:** stress that exposure counts are a screen. Lifting tasks need a recognized assessment method.
