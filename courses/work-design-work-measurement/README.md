# Work Design & Work Measurement

Work measurement, standard data, predetermined time systems, facilities and workplace design.

## Courses

| Course | Topic | Length | Status |
|---|---|---|---|
| [Work Measurement](work-measurement/README.md) | Need for and impact of standards; standard practice; documentation and charting; methods analysis and work design; defining work; time study, elemental analysis, rating, allowances, computations; labor reporting; job analysis; work sampling; standard data and PMTS; learning curves and staffing | ~2 days | v1.0 |
| [Standard Data Systems](standard-data-systems/README.md) | Microscopic vs macroscopic data; advantages and disadvantages; element structure and data sheets; correlation and regression (Excel LINEST/ToolPak); developing models with dummies, transformations and VIF; evaluating with residuals, intervals and hold-out validation; quoting, capacity and maintenance | ~2 days | v1.0 |

| [Predetermined Time Standards (MODAPTS Topics)](predetermined-time-standards/README.md) | Follows the MODAPTS practitioner outline item by item: PMTS basics, acronym, code symbol, history, modular concept, movement classes and rules, get vs put, conscious control, GET/PUT elements, auxiliary activities, practice analyses with an original teaching code card (not the official card), method and ergonomic improvement | ~3 days | v1.0 |
