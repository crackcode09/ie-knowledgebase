# Lean & Six Sigma

Lean, Six Sigma, and the statistical tools behind them: process behavior charts, hypothesis testing, root cause analysis, design for Six Sigma.

## Courses

Suggested order: Measurement & Basic Statistics, Process Mapping and Voice of the Customer, then Charting Process Behavior, then Fundamentals of Hypothesis Testing, then Design for Six Sigma, then Root Cause Analysis. Kaizen Leader and Lean Methods Accelerator have no prerequisites and can be taken at any point.

| Course | Topic | Length | Status |
|---|---|---|---|
| [Measurement & Basic Statistics](measurement-and-basic-statistics/README.md) | Data types, accuracy vs precision, Pareto charts, histograms, center, spread, the normal distribution | ~6 h | draft |
| [Process Mapping](process-mapping/README.md) | SIPOC, flow charts, swim lanes, value-added flow charts, spaghetti diagrams, VSM, VOC, affinity diagrams, CTQ trees, VOC as specifications | ~6 h | draft |
| [Voice of the Customer](voice-of-the-customer/README.md) | Customers and segments, Kano, surveys and margin of error, affinity and CTQ trees, operational definitions, VOC as specifications, cause-and-effect matrix | ~7 h | draft |
| [Lean Methods Accelerator](lean-methods-accelerator/README.md) | Standalone Lean toolkit: COPQ, VSM, takt, balancing, heijunka, benchmarking, flow and cells, SMED, TOC, pull (kanban, CONWIP), 5S, visual management, TPM, standard work | ~18 h | draft |
| [Charting Process Behavior](charting-process-behavior/README.md) | Statistical Process Control: run charts, XmR, X̄–R, attribute charts, capability | ~12 h + capstone | draft |
| [Fundamentals of Hypothesis Testing](fundamentals-of-hypothesis-testing/README.md) | Hypotheses, errors, power, CIs; t, ANOVA, proportion, chi-square, variance and nonparametric tests | ~14 h + capstone | draft |
| [Design for Six Sigma](design-for-six-sigma/README.md) | DCDOV: VOC, QFD, Pugh, FMEA, error-proofing, scorecards, DOE, tolerance stack-up, flow simulation, line balancing, reliability | ~45 h incl. capstone | draft |
| [Root Cause Analysis & Problem Solving](root-cause-analysis/README.md) | Problem statements, Pareto, process maps, fishbone, 5-Why, root cause trees, stratification, regression, logistic regression, corrective actions | ~14 h | draft |
| [Kaizen Leader](kaizen-leader/README.md) | Planning and leading kaizen events: charter, VSM, takt, TOC, flow, balancing, kanban, SMED, 5S, TPM, standard work, A3; includes a one-day team-member track | ~22 h | draft |
