# Glossary

**5S** — Sort, Set in order, Shine, Standardize, Sustain.

**A3** — One-page problem-solving story.

**Andon** — Signal to call for help when a problem occurs.

**Constraint (bottleneck)** — The resource that limits system output.

**Continuous flow** — Moving units one at a time between steps without batching.

**Gemba** — The place where the work happens.

**Heijunka** — Leveling the volume and mix of production.

**Internal / external changeover work** — Work that requires the machine stopped / can be done while it runs.

**Jidoka** — Building in quality: stopping automatically when a problem occurs.

**Kaizen** — Continuous improvement; a kaizen event is a focused 3–5-day improvement.

**Kanban** — Signal card or container that authorizes production or replenishment.

**Muda, mura, muri** — Waste, unevenness, overburden.

**OEE** — Overall equipment effectiveness.

**PCE** — Process cycle efficiency: value-added time ÷ lead time.

**Pull** — Production triggered by downstream consumption.

**SIPOC** — Suppliers, Inputs, Process, Outputs, Customers.

**SMED** — Single-minute exchange of die: quick changeover method.

**Spaghetti diagram** — Floor plan showing the path of product or people.

**Standard work** — Takt, work sequence and standard WIP for a job.

**Supermarket** — Controlled inventory from which downstream pulls.

**Takt time** — Pace of customer demand.

**TPM** — Total productive maintenance.

**Try-storming** — Quickly building and testing rough versions of a solution.

**U-cell** — Cell layout with start and end adjacent so operators can cover non-adjacent steps.

**Value stream map** — One-page map of material and information flow with a lead-time timeline.

**Yamazumi** — Stacked bar chart of work content per operator vs takt.
