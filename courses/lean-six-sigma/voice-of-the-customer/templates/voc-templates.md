## Kano question pair

For feature **[X]**, ask both (answers: I like it / I expect it / I'm neutral / I can live with it / I dislike it):

- Functional: "If [X] were available, how would you feel?"
- Dysfunctional: "If [X] were **not** available, how would you feel?"

## Survey skeleton (≤ 10 minutes)

1. Screening: role, segment, order frequency
2. Importance of needs 1–N (1 = not important … 5 = critical)
3. Satisfaction with us on needs 1–N (1 = very dissatisfied … 5 = very satisfied)
4. Kano pairs for 2–4 features
5. Specification question ("longest acceptable…", "minimum acceptable…")
6. Likelihood to recommend (0–10)
7. One open question: "What one thing should we change?"

## Sample size

n = 1.96² × 0.25 / MOE² (95%, worst case). ±10 → 97; ±7 → 196; ±5 → 385; ±3 → 1,068. Divide by response rate for invitations.
