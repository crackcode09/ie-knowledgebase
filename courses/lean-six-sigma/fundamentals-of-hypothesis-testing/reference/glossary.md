# Glossary

**Alpha (α)** — Significance level; the probability of a Type I error you accept.

**Alternative hypothesis (Hₐ)** — The claim you want evidence for; never contains equality.

**ANOVA** — Analysis of variance; tests whether several group means are equal.

**Beta (β)** — Probability of a Type II error for a specified effect size.

**Confidence interval** — A range produced by a method that captures the true parameter in a stated share (e.g., 95%) of repeated samples.

**Effect size (δ)** — The size of the difference; the smallest one worth detecting drives sample size.

**Fail to reject H₀** — The evidence is not strong enough; not proof H₀ is true.

**Nonparametric test** — A test based on ranks or signs with weak distributional assumptions.

**Null hypothesis (H₀)** — The status quo / no-difference statement; contains equality.

**One-/two-sided test** — Whether Hₐ looks for a difference in one stated direction or either direction.

**p-value** — Probability, assuming H₀ is true, of a result at least as extreme as the one observed.

**Paired design** — Each unit is measured under both conditions; analyze the differences.

**Parametric test** — A test that assumes a distribution family (usually normal) and tests its parameters.

**Power (1 − β)** — Probability of detecting an effect of a given size.

**Practical significance** — Whether an effect is large enough to matter for the decision.

**Standard error** — The standard deviation of an estimate (e.g., s/√n for a mean).

**Statistical significance** — p < α; the result is unlikely under H₀.

**Type I error** — Rejecting a true H₀ (false alarm).

**Type II error** — Failing to reject a false H₀ (missed effect).
