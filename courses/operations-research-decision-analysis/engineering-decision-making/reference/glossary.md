# Glossary

| Term | Meaning |
|---|---|
| **Aleatory uncertainty** | Inherent randomness; not reducible |
| **AHP** | Analytic Hierarchy Process: weights from pairwise comparisons |
| **Borda count** | Rank-points voting rule |
| **Calibration** | How well stated probabilities match observed frequencies |
| **Certainty equivalent** | Sure amount with the same utility as a gamble |
| **Condorcet winner** | Alternative that beats every other one in pairwise majority votes |
| **Decision tree** | Diagram of decisions, chance events and payoffs, solved by rollback |
| **Epistemic uncertainty** | Lack of knowledge; reducible by information |
| **EVPI / EVII** | Expected value of perfect / imperfect information |
| **Fundamental objective** | What you ultimately care about in a decision |
| **Kemeny-Young** | Rank aggregation that maximizes pairwise agreement |
| **Majority judgement** | Voting by grades; ranked by median grade |
| **MAUT** | Multiattribute utility theory: weighted single-attribute utility (value) functions |
| **Means objective** | Matters because it helps achieve a fundamental objective |
| **Mixed strategy** | A random choice among pure strategies with set probabilities |
| **Nash equilibrium** | Strategy profile where no player gains by deviating alone |
| **Potential problem analysis** | Looking ahead at a plan: problems, causes, preventive and contingent actions, triggers |
| **Prisoner's dilemma** | Mixed-motive game where individual incentives lead to a jointly worse result |
| **Risk tolerance (R)** | Parameter of exponential utility; larger means less risk-averse |
| **ROC curve** | Detection rate vs false-alarm rate across thresholds |
| **Saddle point** | Pure-strategy solution of a zero-sum game (maximin = minimax) |
| **Secretary problem** | Optimal stopping when choosing the best of a sequence, with no recall |
| **Stochastic dominance** | Ordering of uncertain prospects valid for broad classes of preferences |
| **Swing weighting** | Weights set by the value of moving each attribute from worst to best |
