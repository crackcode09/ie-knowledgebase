# Glossary

- **AUC / ROC curve:** a model's true-positive rate plotted against its false-positive rate across thresholds; AUC is the area under the curve.
- **Big Data:** data too large, fast or varied for conventional tools (volume, velocity, variety, veracity, value).
- **Classification:** predicting a category from labeled examples.
- **Clustering / segmentation:** grouping similar items without labels.
- **Columnar storage:** storing data by column for fast analytical queries.
- **Confusion matrix:** counts of true and false positives and negatives.
- **Cross-validation:** repeatedly fitting on part of the data and testing on the rest.
- **Dashboard:** a visual display of key metrics for monitoring and decisions.
- **Data governance:** ownership, definitions, quality rules and access policies for data.
- **Data lake / data warehouse:** a store of raw data of any type / a store of curated, modeled history for reporting.
- **Descriptive / diagnostic / predictive / prescriptive analytics:** what happened / why / what will happen / what to do.
- **Dimension table / fact table:** descriptive attributes / events with measures (star schema).
- **Enterprise data model:** organization-wide definitions of key entities and their relationships.
- **Holdout:** data set aside to test a model.
- **Holt-Winters:** exponential smoothing with trend and seasonal components.
- **k-means:** a clustering method that assigns each item to the nearest of k centers.
- **Linear programming:** optimizing a linear objective subject to linear constraints.
- **MAPE:** mean absolute percentage error.
- **Master data:** core shared entities (customer, product, asset) kept consistent across systems.
- **Overfitting:** fitting noise, so the model performs worse on new data.
- **PCA:** principal component analysis.
- **Precision / recall:** the share of flagged cases that are real / the share of real cases that are flagged.
- **Primary / foreign key:** the unique row identifier / a reference to another table's key.
- **Shadow price:** the value of one more unit of a constrained resource.
- **Silhouette score:** a measure of cluster separation.
- **Star schema:** a fact table joined to dimension tables.
- **Tidy data:** one row per observation, one column per variable.
