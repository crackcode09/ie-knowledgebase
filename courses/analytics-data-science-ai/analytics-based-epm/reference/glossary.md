# Glossary

| Term | Meaning |
|---|---|
| **ABC/M** | Activity-based cost management: costing via activities and their drivers, used to manage cost and profit |
| **Activity driver** | Measure of how a cost object consumes an activity (orders, shipments) |
| **Avoidable cost** | Cost that disappears if an activity is stopped or outsourced |
| **Balanced scorecard** | Strategic KPIs across financial, customer, internal-process and learning perspectives |
| **BA / BI** | Business analytics (why, what next, what to do) / business intelligence (what happened) |
| **Chargeback** | Charging shared-service costs to users by drivers of demand |
| **CLV** | Customer lifetime value: discounted future profit from a customer |
| **Cost-to-serve** | Customer-level activity costs: ordering, shipping, returns, support, visits |
| **Driver-based budget** | Budget built from forecast drivers × rates, with capacity steps |
| **EPM** | Enterprise performance management |
| **ERM** | Enterprise risk management |
| **FP&A** | Financial planning and analysis |
| **KPI / PI** | Key performance indicator (strategic) / performance indicator (operational) |
| **KRI** | Key risk indicator: an early signal that a risk is rising |
| **Monte Carlo** | Simulation of outcomes by sampling uncertain inputs |
| **Predictive accounting** | Planning and decision accounting based on forecast drivers and ranges |
| **Resource driver** | Basis for assigning resource cost to activities (effort %, m²) |
| **Rolling forecast** | Forecast refreshed periodically over a fixed horizon (e.g. 5 quarters) |
| **Strategy map** | Diagram of cause-and-effect between strategic objectives |
| **Time-driven ABC** | ABC using time per transaction and the cost per minute of capacity |
| **Value-stream costing** | Lean accounting that assigns costs directly to value streams |
| **Whale curve** | Cumulative profit by customer, ranked from most to least profitable |
