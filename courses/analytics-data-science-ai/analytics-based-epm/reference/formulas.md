# Formulas and Cheat Sheet

| Item | Formula |
|---|---|
| Activity cost | Σ resource cost × resource-driver share |
| Activity rate | activity cost ÷ activity-driver quantity |
| Cost-to-serve (customer) | Σ customer driver quantity × activity rate |
| Customer ABC profit | revenue (net) − direct cost − product-level overhead − cost-to-serve |
| Traditional allocation | overhead × (customer revenue ÷ total revenue) |
| KPI achievement | actual ÷ target (higher is better) or target ÷ actual (lower is better) |
| Weighted scorecard | Σ weight × achievement |
| Logistic model | P(churn) = 1 ÷ (1 + e^−(b₀ + Σ bᵢxᵢ)) |
| AUC | P(score of a random churner > score of a random non-churner) |
| CLV | Σₜ₌₁ⁿ profit × retentionᵗ⁻¹ ÷ (1 + r)ᵗ |
| Unit cost | activity cost ÷ output |
| Excess vs best | (site unit cost − best unit cost) × site volume |
| Absorption vs value-stream profit difference | (units sold − units produced) × standard fixed cost per unit (when inventory falls) |
| Driver-based staffing | forecast driver quantity ÷ capacity per FTE, rounded up per team (or pooled) |
| Log trend + season forecast | ln(revenue) = b₀ + b₁ t + quarter effects; growth per quarter = e^b₁ − 1 |
| Expected risk loss | probability × impact |
| Make-or-buy | compare the supplier's price with **avoidable** cost per unit |
| ROI on analytics | (decision value − cost) ÷ cost |
