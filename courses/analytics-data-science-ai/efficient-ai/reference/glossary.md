# Glossary

| Term | Meaning |
|---|---|
| **AI** | Software that performs judgment-like tasks by learning patterns from data |
| **Automation bias** | Over-trusting automated outputs without checking |
| **Drift** | A model's performance degrading as data or processes change |
| **Fabrication ("hallucination")** | GenAI output that is fluent but unsupported or false |
| **Feature** | An input variable used by a model |
| **Generative AI** | Models that generate text, code or images from instructions and context |
| **Human-in-the-loop** | A person reviews or approves AI output before it takes effect |
| **Label** | The known outcome for a historical example (e.g. the correct ticket category) |
| **Leakage** | Using information in training that isn't available at decision time |
| **Machine learning** | Algorithms that learn to predict or classify from examples |
| **PICK chart** | Value vs effort matrix: Possible, Implement, Challenge, Kill |
| **Precision / recall** | Share of alerts that are real / share of real cases that are alerted |
| **RAG** | Retrieval-augmented generation: retrieve documents, then generate an answer from them |
| **Rules-based automation** | Deterministic if-then logic, including robotic process automation |
| **Threshold** | Cut-off on a model score that triggers an action |
