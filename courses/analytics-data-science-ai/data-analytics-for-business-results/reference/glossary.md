# Glossary

| Term | Meaning |
|---|---|
| A/B test | Randomized experiment comparing a change (B) with a control (A) |
| Apriori | Algorithm that finds frequent itemsets by pruning candidates with infrequent subsets |
| AUC | Area under the ROC curve; probability a model ranks a random positive above a random negative |
| Baseline | Simple rule a model must beat (mean, last value, "nobody churns") |
| Confidence (rule) | P(B given A) |
| Cross-validation | Repeated train/test splits averaged for a stable error estimate |
| Data quality dimension | One aspect of fitness for use (completeness, timeliness …) |
| EDA | Exploratory data analysis: summaries and charts before modelling |
| Leakage | Using information in training that wouldn't be available at prediction time |
| Lift (rule) | Confidence ÷ support of the consequent; >1 = positive association |
| MAD framework | Dashboard layers: Monitor, Analyze, Drill to detail |
| Master data | Slowly changing data about the entities involved (customers, products) |
| Overfitting | Fitting noise in training data so the model generalizes poorly |
| Precision / recall | Share of flagged cases that are right / share of real cases caught |
| RFM | Recency, Frequency, Monetary: a customer description used for segmentation |
| Supervised learning | Learning from examples with known outcomes |
| Survivorship bias | Drawing conclusions only from cases that "survived" a selection |
| Systems of record / engagement / insight | Transaction systems / interaction systems / analysis systems |
| Unsupervised learning | Finding structure in data without known outcomes |
| VA / NVA / NVA-R | Value-adding / non-value-adding / non-value-adding but required |
