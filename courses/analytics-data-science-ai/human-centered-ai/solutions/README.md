## Facilitator notes

- **Module 02:** print the role-play cards. Interviewees reveal items only when asked open questions about real events, which rewards good technique.
- **Module 03:** run the affinity grouping silently at first. Then show the machine-clustering result to make the point about meaning.
- **Module 04:** have groups write HMWs that are too broad and too narrow on purpose, then fix them.
- **Module 05:** stress the 5 of 12 result: speed alone doesn't create adoption.
- **Ethics:** remind participants about consent, anonymity, and never using interview content to evaluate individuals.
