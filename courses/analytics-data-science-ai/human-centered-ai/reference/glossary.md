# Glossary

| Term | Meaning |
|---|---|
| **Affinity grouping** | Clustering observations by shared underlying meaning |
| **Assumption mapping** | Ranking assumptions by importance and evidence to decide what to test first |
| **Concierge test** | Delivering a service manually and openly to test its value |
| **Contextual inquiry** | Interviewing people while observing them do their work in their own environment |
| **Convergent thinking** | Narrowing options into a few choices or themes |
| **Design sprint** | A short, time-boxed process from problem to tested prototype (often five days) |
| **Divergent thinking** | Generating or gathering many options without judging |
| **Double diamond** | Diverge-converge on the problem, then on the solution |
| **Fake door** | An interface element that measures interest in a feature not yet built |
| **Gemba** | The place where the work is done (Lean term) |
| **HCD** | Human-centered design |
| **How might we (HMW)** | An opportunity statement that invites solutions without fixing one |
| **Theme** | A named pattern across observations, written as a sentence |
| **Wizard of Oz** | A prototype where a human secretly produces the system's responses |
| **Workaround** | Something people do to get around an unmet need; strong evidence of a pain |
