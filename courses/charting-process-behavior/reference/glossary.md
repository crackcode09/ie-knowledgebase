# Glossary

**Assignable cause / special cause** — A specific, identifiable source of variation that is not part of the routine process. Shows up as a signal on a chart.

**Attribute data** — Counts: defectives (good/bad units) or defects (flaws per unit).

**Baseline** — The period of data used to compute limits, which are then frozen and extended.

**Capability (Cp, Cpk)** — Ratio of the specification width to the process's natural (within) spread; Cpk accounts for centering.

**Common cause / routine variation** — The combined effect of many small, always-present sources; the noise of a predictable process.

**Control chart / process behavior chart** — Time-ordered plot with a center line and limits computed from the data, used to separate signal from noise.

**d₂** — Constant converting average range to sigma for subgroup size n.

**Detection rules** — Patterns that indicate a special cause (point beyond limits, runs, etc.).

**DMAIC** — Define, Measure, Analyze, Improve, Control; a structured improvement roadmap.

**EWMA / CUSUM** — Charts with memory, more sensitive to small sustained shifts.

**Histogram** — Bar chart of the frequency of values within bins; shows center, spread and shape.

**Moving range (mR)** — Absolute difference between consecutive individual values.

**Natural process limits** — Limits on an individuals chart (X̄ ± 2.66 mR̄); where individual values of a predictable process fall.

**Operational definition** — A precise description of how a value is obtained, so different people get the same result.

**Performance (Pp, Ppk)** — Capability-like indices using overall standard deviation.

**Predictable / in statistical control** — Shows only common-cause variation over time.

**Rational subgroup** — Measurements collected so that only common-cause variation occurs within the subgroup.

**Run chart / trend chart** — Time-ordered plot with a median line; no limits.

**Specification limits** — Customer or engineering requirements for individual units. Not the same as control limits.

**Stage variable / stratification** — A grouping factor (machine, shift, lot) used to split data and reveal hidden sources of variation.

**Tampering** — Adjusting a stable process in response to common-cause variation; increases variation.
