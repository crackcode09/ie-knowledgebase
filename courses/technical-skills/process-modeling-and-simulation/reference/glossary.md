# Glossary

**Activity** — Work that takes time in a model.

**Arrival process** — How entities enter the model (rate, pattern, randomness).

**Build to think** — Using quick models to explore and learn rather than only to predict.

**Coefficient of variation (CV)** — Standard deviation ÷ mean; a scale-free measure of variability.

**Common random numbers** — Using the same random streams across designs so comparisons reflect design differences.

**Confidence interval** — Range likely to contain the true mean of a KPI, from replications.

**Discrete-event simulation (DES)** — Model that advances from event to event in time.

**Dispatch rule** — Rule choosing which waiting entity a resource serves next (FIFO, SPT, priority).

**Entity** — The thing flowing through a process model.

**Event list** — Time-ordered list of future events in a DES.

**Kingman approximation** — Wq ≈ [(CVa² + CVs²)/2] × [u/(1 − u)] × service time.

**Pooling** — Sharing resources across tasks to reduce waiting.

**Replication** — An independent run of a stochastic model.

**Resource** — Capacity that performs activities (people, machines).

**Routing** — Paths and branches entities follow.

**Terminating simulation** — Model with a natural start and end (e.g., a day), needing no warm-up.

**Utilization** — Busy time ÷ available time.

**Validation** — Checking the model represents reality well enough for its purpose.

**Verification** — Checking the model works as intended.

**Warm-up period** — Initial simulated time discarded in steady-state models.
