# Dashboard Metric Definitions

Write each metric down once. Use the same definition every period.

| Metric | Formula | Data source | Owner | Frequency | Target | Good direction |
|---|---|---|---|---|---|---|
| Gross margin % | gross profit / revenue | monthly P&L | Controller | monthly | | up |
| Cell contribution margin | (revenue − variable cost) / revenue | cell P&L | Cell manager | monthly | | up |
| Operating profit vs budget | actual − flexible budget | budget report | Cell manager | monthly | ≥ 0 | up |
| DSO (days) | receivables / revenue × 365 | AR ledger | Credit | monthly | | down |
| Inventory days (cell) | cell inventory / cell COGS × 365 | ERP | Cell manager | monthly | | down |
| Cash conversion cycle | DSO + DIO − DPO | balance sheet | Controller | monthly | | down |
| Scrap % | scrap $ / production $ | MES / quality | Quality | weekly | | down |
| OEE % | availability × performance × quality | MES | Cell manager | weekly | | up |
| On-time delivery % | orders shipped on time / orders due | ERP | Planning | weekly | | up |
| Capital projects on track | projects meeting post-audit savings / total | capital log | Engineering | quarterly | | up |

Notes:
- State the period (month, quarter-to-date, trailing 12 months) for every metric.
- Show the comparison (prior period or budget) and color by good or bad direction, not by up or down.
