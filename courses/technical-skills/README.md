# Technical Skills

Core IE technical topics: statistics, design of experiments, process modeling, reliability, financial management.

## Courses

| Course | Topic | Length | Status |
|---|---|---|---|
| [Introduction to Industrial Engineering](introduction-to-industrial-engineering/README.md) | What IEs do; methods and motion study; time study, work sampling and standards; ergonomics; layout; job analysis, evaluation and pay; Lean, Six Sigma, RCA; basic statistics | ~3 days | v1.0 |
| [Applied Statistics](applied-statistics/README.md) | Data collection systems; descriptive statistics; hypergeometric, binomial, Poisson, normal, exponential, t, chi-square, F; CIs and tests; non-normal data; correlation; linear and multiple regression | ~2 days | v1.0 |
| [Design of Experiments](design-of-experiments/README.md) | Completely randomized, randomized block and Latin square designs; two-factor ANOVA and interaction; balanced vs unbalanced; replication and power; 2^k full and fractional factorials; operating levels with cost | ~2 days | v1.0 |
| [Process Modeling and Simulation](process-modeling-and-simulation/README.md) | Discrete-event process models: build to think, validation, design exploration, resilience testing, operating procedures, model-based FMEA, business case, teaching Lean | ~7 h | v1.0 |
